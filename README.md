# OKSat — Electrical Power System Simulation
**Oklahoma State University | Senior Design | Spring 2026**

MATLAB/Simulink model for electrical power system (EPS) and thermal analysis of the OKSat 3U CubeSat over a 5-year mission in Low Earth Orbit. Developed by the EPS subsystem team as part of OSU's senior capstone program. Originally based on CodrutRomas' 6U PolySat simulation, redesigned for OKSat.

## Attitude & Body Frame Convention

OKSat uses an **Earth-Centered Inertial (ECI)** reference frame for all orbital and attitude computations.

| Axis | Direction |
|---|---|
| +Z | Anti-nadir (away from Earth) |
| +X | Velocity (ram direction) |
| +Y | Cross-track (Z × X) |

## Simulation Architecture

The simulation is built around a MATLAB/Simulink model (`main_simulation.slx`) loaded with parameters from `params_simulink.mat`. All parameters are initialized and saved via `init_parameters.m` before each run.

### Subsystem Models

**Solar Array** (`solar_array_model.m`)
Computes per-panel power using cosine illumination law, linear BOL→EOL efficiency degradation (29.8% → 23.8% over 5 years), temperature derating (−0.25%/°C above 28°C reference), and an energy-balance thermal node. Orbital attitude is modeled with a DCM rotation from `attitude_determination.m`; body-frame panel normals account for the ±45° body-mount geometry and the four deployed panels.

**Battery** (`battery_voltage_model.m`, `battery_degradation_model.m`, `battery_efficiency_model.m`)
Models a GomSpace BPX 4S-2P pack. The OCV curve uses a 4S-series polynomial fit derived from the GomSpace 18650 cell datasheet. Degradation tracks both calendar aging (exponential decay) and cycle-life fade (linear to 80% capacity at rated cycle count). Charge efficiency is 95%; discharge efficiency is C-rate dependent (92–98%).

**Power Mode FSM** (`power_mode_fsm.m`)
Three-state finite state machine (Safe / Nominal / Science) with hysteresis thresholds to prevent oscillation. In steady-state the battery floats near 95–100% SOC, so the FSM nominally holds Science mode — this is physically correct, not a bug.

```
Safe Mode     (SOC < 0.70)
  │  SOC > 0.80
  ↓
Nominal Mode  (0.80 < SOC < 0.90)
  │  SOC > 0.90
  ↓
Science Mode  (SOC > 0.90)
  │  SOC < 0.80
  └→ Nominal
```

**Power Mode Load Budget**

| Mode | Load |
|---|---|
| Safe | ~2.0–2.24 W |
| Nominal | ~6.14 W |
| Peak / Science | ~9.14–12.44 W |
| TX delta (ground contact) | +2.64 W |

**Eclipse Detector** (`eclipse_detector.m`)
Geometric shadow computation from GMAT ephemeris. Also drives the standalone 2D/3D visualizations.

**MPPT / PCDU** (`mppt_algorithm.m`)
Simulates ACU-200 MPPT at 90% efficiency with PDU-200 DC/DC conversion losses (~3%). Routes power: solar → load, excess → battery, deficit → battery discharge.

**Heater Controller** (`heater_controller.m`)
Thermostat-style control for battery thermal management during eclipse. Heater activates below 15°C with ±2.5°C deadband; max heater power 6 W per BPX datasheet.

## Quick Start

1. **Initialize Parameters**

    ```matlab
    run('init_parameters.m')
    ```

    > ⚠️ **Critical:** Simulink loads parameters from `params_simulink.mat` at runtime. If this file is missing or stale, Simulink silently ignores block edits and uses cached values. The fix is always: run `init_parameters.m` → save MAT-file → `bdclose all` → reopen and run.

2. **Run the full 5-year simulation**

    ```matlab
    run('full_sim.m')
    ```

3. **Generate Plots**

    ```matlab
    run('plots.m')
    ```

4. **View Results**
    - Console output: comprehensive mission summary printed on completion
    - Workspace: `results_5y` struct with all metrics

5. **Standalone Visualizations** (no Simulink required — runs directly from GMAT ephemeris)

    ```matlab
    run('oksat_eps_viz.m')   % 4-panel 2D animated EPS dashboard
    run('oksat_3d_viz.m')    % 3D orbital visualization
    ```

## Custom Simulations

### Modify Duration

```matlab
init_parameters;
params = evalin('base', 'params');
params.sim.duration        = 30 * 24 * 3600;  % e.g. 1 month in seconds
params.sim.duration_orbits = params.sim.duration / params.orbit.period;
assignin('base', 'params', params);
out = sim('main_simulation', 'SrcWorkspace', 'base');
```

### Change Solar Configuration

```matlab
% Body-only (2 panels, conservative lower bound)
params.solar.num_panels      = 2;
params.solar.area_per_panel  = 0.018;          % 6 cells × 30 cm² per panel [m²]
params.solar.total_area      = 0.036;          % [m²]
assignin('base', 'params', params);

% Full deployed (6 panels, nominal mission config)
params.solar.num_panels      = 6;
params.solar.area_per_panel  = 0.018;
params.solar.total_area      = 0.108;          % [m²]
assignin('base', 'params', params);
```

### Adjust Solver

```matlab
% Faster, lower accuracy (good for long runs)
params.sim.max_step = 100;   % larger timestep [s]
params.sim.reltol   = 1e-4;

% Slower, higher accuracy (good for short diagnostic runs)
params.sim.max_step = 10;
params.sim.reltol   = 1e-5;
assignin('base', 'params', params);
```

### Set Initial SOC

```matlab
% Start at 50% to observe full charge dynamics / stress-test eclipse survival
params.battery.SOC_initial = 0.50;
assignin('base', 'params', params);
```

### Tune FSM Thresholds

```matlab
params.power_mode.safe.soc_enter         = 0.70;
params.power_mode.safe.soc_exit          = 0.80;
params.power_mode.nominal.soc_exit_high  = 0.90;
params.power_mode.science.soc_enter      = 0.90;
params.power_mode.science.soc_exit       = 0.80;
assignin('base', 'params', params);
```

### Change Mission Start Year

```matlab
% Affects solar degradation fraction at t=0
params.mission.start_date = datetime(2026, 1, 1, 0, 0, 0);
assignin('base', 'params', params);
```

## Design Decisions & Notes

**Battery oversizing is intentional.** The BPX provides ~10× the eclipse energy requirement, giving ~27-hour safe-mode survival, robust heater margin, and a 5-year degradation buffer. Configuration is 4S-2P (not 8S-1P) for P60 16V bus compatibility and string-level redundancy.

**Body-only solar is insufficient.** Body-mounted panels alone yield ~2.39 W EOL orbit-mean — below the nominal load. The four DSP deployable panels are mission-critical.

**DOD floor is 25% DOD / 75% SOC minimum.** This is the defensible limit for high cycle-count LEO missions per Patel & Beik *Spacecraft Power Systems* 2nd ed.

**Cycle counting:** ~26,950 orbital cycles over 5 years, but only ~5,475 equivalent full cycles at ~20% DOD. Cycle life values are referenced to GomSpace BPX (DS 1076870) and GomSpace 18650 cell (DS 1022248).

**FSM never cycles in steady-state** because the battery never meaningfully discharges — OKSat floats near 95–100% SOC. This is physically correct behavior, not a simulation bug.

---

## Limitations

- Simplified orbital mechanics: near-circular orbit, fixed eclipse fraction (no beta angle variation)
- Single thermal node per panel: no spatial temperature gradients
- No anomaly modeling: constant load profiles, no component failure scenarios
- Attitude assumed sun-pointing for solar calculations; nadir-pointing sinusoidal profile used in standalone visualizations as a conservative lower bound
